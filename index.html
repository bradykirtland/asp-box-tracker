Search by size — fill any box, leave the rest blank. Press space to jump to the next box.

Boxes are listed by length (the first dimension), shortest first. Use +/− to adjust counts — changes save for everyone automatically. To add or remove areas and box sizes, use the Add / Manage tab.

Add area creates a new location. Add box size creates a new box (dimensions like 12x6x6, plus an optional restock-warning level). New items appear on the Tracker tab, where you set their counts. Deleting an area or box size removes it for everyone.
